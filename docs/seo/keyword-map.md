# نقشه کلمات کلیدی کیدوکی

این نقشه بر اساس نیت جست‌وجو نوشته شده است، نه حجم یا سختی فرضی. حجم جست‌وجو، CTR، رتبه و تبدیل باید بعد از راه‌اندازی با Search Console و داده فروش بررسی شود.

| نیت اصلی | عبارت‌های نمونه | مقصد اصلی | یادداشت جلوگیری از هم‌پوشانی |
| --- | --- | --- | --- |
| خرید عمومی | خرید لباس بچگانه | صفحه محصولات | صفحه عمومی؛ متن آن با دسته‌ها رقابت نکند |
| دخترانه | لباس دخترانه بچگانه، خرید ست دخترانه، پیراهن دخترانه بچگانه | دسته دخترانه | برای ست و پیراهن صفحه جدا نسازید مگر موجودی و محتوای مستقل داشته باشد |
| پسرانه | لباس پسرانه بچگانه، خرید ست پسرانه | دسته پسرانه | فیلترها برای رنگ/سایز؛ نه صفحات شهری |
| نوزادی | لباس نوزادی، راهنمای خرید لباس نوزاد | دسته نوزادی + مقاله راهنما | مقاله پاسخ آموزشی است؛ دسته مقصد خرید است |
| محصول/لباس | بلوز شلوار بچگانه، کاپشن بچگانه، لباس راحتی کودک | دسته یا محصول واقعی موجود | فقط وقتی موجودی، عکس و محتوای تأییدشده وجود دارد |
| اطلاعات سایز | راهنمای سایزبندی لباس کودک | راهنمای سایز + مقاله | جدول فقط با اندازه‌های supplied by merchant منتشر شود |

عبارت‌های «سراسر ایران» و نام شهرها نباید به‌صورت مصنوعی به صفحات اضافه شوند. پوشش ارسال فقط بر اساس قوانین واقعی ارسال نمایش داده شود. صفحات شهرمحور ساخته نشوند.

## اعتبارسنجی بعدی

Search Console برای query، landing page، کشور، دستگاه و CTR استفاده شود؛ Analytics/فروش برای سنجش add-to-cart و خرید استفاده شود. هیچ عددی در این سند پیش‌بینی رتبه یا عملکرد نیست.
