# First 90 days after launch

## Days 1–30

- Verify HTTPS redirects, canonical host, robots and every sitemap in Search Console.
- Remove demo products and publish only photographed, complete products.
- Submit the sitemap and inspect representative product/category/article URLs.
- Validate Product/ProductGroup markup and price currency conversion with the official rich-result tools.

## Days 31–60

- Use Search Console queries and landing pages to validate or revise the keyword map.
- Publish genuinely useful size, seasonal and care guides tied to real categories.
- Review crawl exclusions, soft 404s, duplicate canonical signals and product availability behavior.
- Measure mobile LCP, INP and CLS with field data; optimize the largest real bottlenecks.

## Days 61–90

- Improve pages with impressions but weak CTR using truthful titles/descriptions.
- Expand only categories with real inventory and differentiated customer intent.
- Review image-search impressions and improve filenames, alt text and photography where evidence supports it.
- Establish a monthly SEO release checklist covering metadata, schema, sitemap, redirects and stock lifecycle.
