# دفترچه محتوای دسته‌ها

هر دسته indexable باید H1 یکتا، عنوان و توضیح متا، معرفی کوتاه، راهنمای خرید مرتبط، لینک والد/فرزند و در صورت وجود FAQ واقعی داشته باشد. شبکه محصول باید پیش از متن طولانی دیده شود؛ راهنمای تکمیلی پایین grid قرار می‌گیرد.

فرم اداری فیلدهای intent، buying guide، FAQ JSON، دسته‌های مرتبط و وضعیت draft/needs_review/approved را نگه می‌دارد. FAQها باید سؤال واقعی مشتری و پاسخ قابل اثبات باشند؛ FAQ schema عمداً اضافه نشده است.
