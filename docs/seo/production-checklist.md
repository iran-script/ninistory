# چک‌لیست انتشار SEO

- `APP_ENV=production` و `APP_DEBUG=false`.
- `APP_URL` دامنه canonical و HTTPS باشد؛ redirect سمت وب‌سرور HTTP به HTTPS را فعال کنید.
- `SEO_INDEXING_ENABLED=true` فقط پس از حذف/غیرفعال‌کردن کاتالوگ آزمایشی و تکمیل اطلاعات کسب‌وکار.
- در مدیریت سئو، گزینه «اجازه ایندکس» را فقط در production فعال کنید.
- `robots.txt` و همه فایل‌های sitemap را با دامنه HTTPS بررسی و در Search Console ثبت کنید.
- صفحات محصول باید عکس واقعی، عنوان، توضیح و قیمت معتبر داشته باشند؛ placeholder به عنوان عکس محصول منتشر نشود.
- نام دامنه canonical، اطلاعات تماس، قوانین ارسال/مرجوعی و حریم خصوصی تکمیل شود.
- Search Console، GA4 و Merchant Center فقط با شناسه‌های واقعی و پس از بررسی حریم خصوصی تنظیم شوند.
- Lighthouse و Core Web Vitals روی دستگاه واقعی و شبکه واقعی پایش شوند؛ نتیجه محلی تضمین رتبه یا امتیاز میدانی نیست.
- قبل از انتشار، sitemap، JSON-LD و status code صفحات حذف‌شده با ابزارهای رسمی بررسی شوند.
