# چک‌لیست انتشار محتوا

1. مشخصات و تصاویر توسط فروشنده بررسی شده باشد.
2. دسته/محصول canonical، robots و JSON-LD صحیح داشته باشد.
3. لینک‌های داخلی و راهنمای سایز واقعی باشند.
4. محتوای مقاله approved و نویسنده/بازبین واقعی ثبت شده باشد.
5. محصول دمو در production یا sitemap/indexing نباشد.
6. PHPUnit، browser tests، build، view cache و performance checks اجرا شده باشند.
7. تا آماده‌شدن محصولات واقعی، سیاست‌ها، DNS/HTTPS و Search Console، indexing production فعال نشود.
